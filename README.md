# Foody Scraper

Auto-scrape restaurant data from Foody.vn

## Setup

```bash
pip install requests
python scrape_foody_github.py
```

## GitHub Actions

- Runs every 3 hours automatically
- Data saved to `data/venues.json`
- Uses GitHub repo as storage

## Manual Run

Go to Actions tab → "Scrape Foody" → "Run workflow"
